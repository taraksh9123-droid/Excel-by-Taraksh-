Excel Flow: spreadsheet with AI assistance

Excel Flow is a browser-based spreadsheet for entering data, writing formulas, analyzing tables, and creating charts. Adjust cell sizes, format ranges, and use the workbook assistant to make supported edits faster.

About the creator

Excel Flow was created by Taraksh Choudhary, a 13-year-old Indian developer interested in spreadsheets, automation, and AI-powered tools. Visit Taraksh Choudhary on GitHub.

Spreadsheet features

  • Enter and format workbook data with adjustable rows and columns.
  • Use formulas and functions for everyday calculations.
  • Sort data, work with ranges, and create visual charts.
  • Ask the Excel Flow AI assistant for workbook-aware help.
